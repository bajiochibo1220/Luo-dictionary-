PLATFORM (PHASE 1)
1.0 BACKGROUND
The LuoLinguaAI platform is a digital ecosystem designed to preserve, document, and promote the Dholuo language and
Luo  cultural  heritage  through  Artificial  Intelligence.  This  initiative  aligns  with  JOOUST's  strategic  objectives  in
Technology-Enabled  Learning  (TEL)  and  digital  content  creation,  and  builds  on  existing  research  and  cultural
documentation already undertaken at the University. 
This Phase 1 development is positioned within the broader context of the NRF-funded AI-enabled digital repository for
Luo Indigenous Knowledge Systems, which covers Homa Bay, Kisumu, and Siaya counties. Phase 1 will therefore be
designed with future integration to the NRF repository architecture in mind, ensuring alignment on data models, file
naming conventions, and API readiness. 
2.0 SCOPE (PHASE 1)
This initial phase will deliver a functional web-based minimum viable product (MVP) including: 
Comprehensive dictionary module (Luo ↔ English)
Proverbs and riddles repository
Oral history archive
Basic administrative dashboard
Live hosted web portal
Alignment with NRF Repository:
ASPECT PHASE 1 APPROACH NRF REPOSITORY STANDARD
Data Models Will adopt core object structure (CulturalRecord, Media Asset, Transcript) As specified in NRF TechnicalSpecifications
File Naming Will use deterministic URIs with asset_idand checksums /JOOUST/NRF/LuoAI_Repository/...

3.0 DEVELOPMENT TEAM AND BUDGET JUSTIFICATION
The budget of KES 300,000 covers a lean development team of two (2) personnel over a six-week period, plus essential
infrastructure costs. The breakdown is as follows: 
ROLE QUANTITY DURATION DAILY RATE (KES) TOTAL (KES)
Full Stack Developer 1 30 days 5,000 150,000
UI/UX Designer + QA 1 20 days 4,000 80,000
Subtotal - Personnel 230,000
Hosting & Infrastructure 40,000
Contingency 30,000
GRAND TOTAL 300,000
Justification:
Full Stack Developer (KES 150,000): Responsible for backend development, database architecture, API integration,
frontend web development, and deployment. This developer will also ensure alignment with NRF data models and
naming conventions. This is a senior-level developer required to deliver a functional platform within the tight six-week
timeline.
UI/UX Designer + QA (KES 80,000): Responsible for user interface design across all modules, user experience
testing, and quality assurance to ensure the platform is functional and user-friendly.
Hosting & Infrastructure (KES 40,000): Covers cloud hosting services, domain registration, database hosting, and
SSL certificate for secure deployment.
Contingency (KES 30,000): For unforeseen expenses, additional server resources, or minor scope adjustments during
development.
4.0 TIMELINE
The development will be completed within six (6) weeks from the date of funding approval, leveraging the existing
Dholuo dataset already compiled through prior research efforts at JOOUST.
