# Luo Heritage identity

The open book represents language and shared knowledge, the rising sun represents continuity across generations, and the flowing water connects the collection with the lake landscape.

`luo-heritage.svg` is the original scalable artwork. Run `node scripts/generate-brand-icons.cjs` to render the 32, 180, 192, 512, and 1024 pixel PNG icons. Apple and maskable icons use an opaque background. The admin variant adds a shield badge; the older SVG URLs remain available for existing installations.
