# Local application fonts

These are the same Inter and Lora WOFF2 subsets previously emitted by Next's Google font loader for this application. They are copied byte-for-byte from the existing successful build cache. `fonts.css` retains their original weight, style and Unicode ranges, including extended Latin characters.

The application serves these files locally so development startup and production builds do not depend on a Google Fonts network request. Both fonts use the SIL Open Font License; the original notices are included in `Inter-OFL.txt` and `Lora-OFL.txt`.

Original license sources:

- https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt
- https://github.com/google/fonts/blob/main/ofl/lora/OFL.txt
