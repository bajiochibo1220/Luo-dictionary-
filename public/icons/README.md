# Luo Heritage identity

The open book represents language and shared knowledge, the rising sun represents continuity across generations, and the flowing water connects the collection with the lake landscape.

`luo-heritage.svg` is the original scalable artwork. Run `node scripts/generate-brand-icons.cjs` to render the 32, 180, 192, 512, and 1024 pixel PNG icons, the Apple fallback, and the native Windows/browser ICO. All installation PNGs use an opaque background. Public and admin installations use the same artwork; the older icon URLs remain available as identical aliases for existing installations. The operating system may apply its own outer shape to a launcher icon.
